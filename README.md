# My Mini Mart (web build)

Unity WebGL build of My Mini Mart, linked from the game hub at
https://poke5121999-art.github.io/survivor-web-hub/ as `casual-farm`.

The game, its art, models and sound belong to Kiseki Games / Supersonic. This is a personal,
non-commercial web port: ads grant their reward immediately, purchases are free, and no SDK runs.

`Build/parts.json` lists the data file's parts; `index.html` joins them before starting Unity, because
GitHub Pages serves no file over 100 MB.
